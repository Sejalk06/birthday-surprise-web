# Aashu Birthday Website

## Folder structure
- index.html — complete website and original JavaScript/features
- style.css — original CSS plus the new romantic memories/video styling
- photos/photo01.jpg ... photo09.jpg — the 9 uploaded couple photos
- videos/aashu-birthday.mp4 — uploaded birthday video

## GitHub Pages
1. Create a GitHub repository named `Aashu-Birthday`.
2. Upload `index.html`, `style.css`, the `photos` folder, and the `videos` folder.
3. In GitHub: Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.
4. After GitHub finishes publishing, the expected Pages address for username `Sejalk06` is `https://sejalk06.github.io/Aashu-Birthday/`.

Do not rename the photo/video files unless you also update the paths in index.html.
